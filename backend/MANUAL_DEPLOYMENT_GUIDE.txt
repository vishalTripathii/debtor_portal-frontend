🆘 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

Problem: "Access Denied" when uploading
Solution: 
- Ask AWS administrator to temporarily grant lambda:UpdateFunctionCode
- OR use AWS Console login with higher permissions
- OR share the email.zip file with someone who has permissions

Problem: Code uploaded but tests failing
Solution:
- Check CloudWatch logs for detailed error
- Verify environment variables are correct
- Check node_modules/nodemailer is included in ZIP

Problem: Emails not sending
Solution:
- Verify EMAIL_HOST_PASSWORD = Welcome@123 (case sensitive)
- Check SMTP settings: port 587, TLS enabled
- Test from different email client to rule out server issues
